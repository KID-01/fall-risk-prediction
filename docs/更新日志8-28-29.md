# 更新日志 8/28-29

## 视觉模型接入与风险融合

- 正式接入 `yolo26n-pose.pt` 与 `yolo26n.pt`，Pose 单次推理同时返回人体框、关键点和质量状态。
- 支持多人检测并稳定选择主人物；所有人体框可叠加显示，主人物用于步态、轨迹和风险计算。
- 环境检测拆分人物与环境目标，环境模型每 3 个处理帧运行一次，并使用 1 秒缓存有效期。
- 实现人物脚点邻近风险、下半身重叠过滤、照明、脚部通道障碍、轨迹预测和路径交互风险。
- Wet Floor 在缺少可靠权重时明确返回 `UNKNOWN`，不伪造检测结果。
- 新增分层保守融合：人体、环境、交互分项统一为 0–100 工程风险分，环境型升级连续确认 3 次、降级连续确认 5 次。
- 告警支持升级、原因变化和 60 秒提醒冷却，风险更新与告警通过 WebSocket 推送。

## API 与数据兼容

- `GET /api/v1/risk/current` 增加标准化 `person`、`motion`、`environment`、`risk_extensions` 和 `fusion` 结构。
- 保留 `human_detected`、`environment_count`、`environment_boxes`、`illumination` 等旧兼容字段。
- SQLite 风险记录增加评分来源、人体/环境/交互分项和原因码；旧 `mahalanobis_v0` 记录转换为 0–100 展示分并保留原始值。
- 音频事件、文件音频和萤石分析流统一使用监控启动后的相对时间轴；修复默认时间戳和自动音频源选择。

## 前端界面

- 合并远程提交 `b451b04` 的暖纸/暖墨双主题、青绿色视觉 token、衬线标题、圆角卡片、玻璃质感和背景图。
- 新增页面 favicon、可选 Google Fonts 及本地字体回退，离线时不影响页面使用。
- 保留综合工程风险仪表盘，显示标准化分数并保留一位小数。
- 趋势图直接使用标准化风险分，并按数据范围动态缩放纵轴以放大变化。
- 环境侧栏展示模型状态、识别目标、危险物贡献、邻近距离、缓存过期和各 provider 状态；桌面端可拖拽宽度，移动端自动堆叠。
- 音频监测图表、波形和声音事件标签采用远程青绿色风格。

## 验证结果

- 全量后端测试：`262 passed`。
- 前端生产构建：`npm.cmd run build` 通过。
- 真实视频 30 帧烟测：Pose 30/30 帧识别到人体，环境推理 10 次，缓存年龄小于 1 秒，无模型异常。
- 观测到主循环最大耗时约 2.64 秒，满足 `max_latency_ms=3000` CPU 验收要求。
