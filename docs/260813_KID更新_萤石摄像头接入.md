## 一、后端启动 & 端口占用处理

### 问题
`demo_report.py` 报错 `httpx.ConnectError: 由于目标计算机积极拒绝，无法连接`，原因是后端未启动。

### 解决
启动后端时发现端口 8000 被旧进程占用：

```powershell
# 查找占用端口 8000 的进程
Get-Process -Id (Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | Select-Object -ExpandProperty OwningProcess)

# 强制终止
Stop-Process -Id 25596 -Force

# 启动后端
venv\Scripts\python.exe -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000
```

## 二、RTMP 流接入测试

### RTMP 方式（✅ 可行）

萤石摄像头 RTMP 地址格式：

```
rtmp://rtmp01open.ys7.com:1935/v3/openlive/BK8392637_1_1
```

**无鉴权参数**：可以连接，但连接较慢（约 15 秒），流容易耗尽并自动重连。

**带鉴权参数**：通过萤石 API 获取带时效性 token 的地址，连接更快更稳定。

获取鉴权地址的方法：

```python
# 从 configs/ezviz.yaml 读取 app_key 和 app_secret
from src.ezviz.client import EzvizClient

client = EzvizClient(app_key="ba7ff1689b774d00bf17b1d668d9b342", app_secret="c33aaa2e5cf0d8b488776950dde505ee")
rtmp = await client.get_live_stream("BK8392637", protocol=2)  # 2=RTMP
```

### RTSP 方式（❌ 不可行）

萤石 API 返回的"RTSP 地址"实际是 HTTP-FLV 格式（`https://rtmp09open.ys7.com:9188/...`），不是标准 RTSP 协议，OpenCV 无法读取。**结论：只能用 RTMP。**

### 测试结果

| 方式 | 帧数 | 有效帧 | 结论 |
|------|------|--------|------|
| RTMP（无鉴权） | 有增长 | 0 | ✅ 可读帧，连接慢 |
| RTMP（带鉴权） | 有增长 | 0 | ✅ 可读帧，更稳定 |
| RTSP（带鉴权） | 0 | 0 | ❌ 读不到帧 |

> 有效帧为 0 是因为摄像头画面中无人，YOLO 检测不到人体，属于正常行为。

## 三、demo_report.py 输出缓冲问题

### 问题
直接运行 `demo_report.py` 时终端无输出，但后端日志显示 API 请求正常到达。

### 解决
Python print 输出被缓冲，需加 `-u` 参数：

```powershell
venv\Scripts\python.exe -u scripts\demo_report.py --source "rtmp://rtmp01open.ys7.com:1935/v3/openlive/BK8392637_1_1"
```

## 五、前端"启动监控"按钮修复

### 问题
前端按钮点击后无效，原因是 `source` 硬编码为 `'0'`（本地摄像头），未使用 RTMP 地址。

### 修改内容

**`frontend/src/App.jsx`**：

1. 新增状态变量 `source` 和 `personId`（默认值从 localStorage 读取，持久化记忆）
2. `startMonitor` 函数改为使用状态变量而非硬编码值
3. 新增两个输入框：视频源地址、被监测人 ID

```jsx
// 状态定义
const [source, setSource] = useState(() =>
  localStorage.getItem('monitor_source') || 'rtmp://rtmp01open.ys7.com:1935/v3/openlive/BK8392637_1_1'
)
const [personId, setPersonId] = useState(() =>
  localStorage.getItem('monitor_person_id') || 'default'
)

// 启动函数
const startMonitor = async () => {
  localStorage.setItem('monitor_source', source)
  localStorage.setItem('monitor_person_id', personId)
  await fetch(`${API_BASE}/stream/start`, {
    method: 'POST', headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ source, person_id: personId }),
  })
  fetchStatus()
}
```

**`frontend/src/index.css`**：新增 `.control-inputs`、`.control-inputs input`、`.control-buttons` 样式。

## 六、监控自动停止条件

### demo_report.py 的 3 分钟限制

`demo_report.py` 第 87 行 `for i in range(60)` 轮询 60 次 × 3 秒 = 180 秒，时间到后自动调用 stop API。**这只是演示脚本的限制，不是系统本身的限制。**

### 系统真正的停止条件

| 条件 | 说明 |
|------|------|
| 本地视频文件播完 | `read_frame()` 返回 None，循环结束 |
| 网络流重连失败 | RTMP 流耗尽后自动重连，重连失败才会停止 |
| 代码异常 | 监控线程内未捕获异常 |
| 手动调用 API | `POST /api/v1/stream/stop` |

对于萤石 RTMP 流，**不会自动停止**，会持续重连。

### 不限时启动监控的命令

```powershell
# 停止旧监控
venv\Scripts\python.exe -c "import httpx; httpx.post('http://localhost:8000/api/v1/stream/stop',timeout=10)"

# 启动新监控（不限时）
venv\Scripts\python.exe -c "import httpx; httpx.post('http://localhost:8000/api/v1/stream/start', json={'source': 'rtmp://rtmp01open.ys7.com:1935/v3/openlive/BK8392637_1_1', 'person_id': 'user1', 'device_id': 'cam1'})"

# 查看状态
venv\Scripts\python.exe -c "import httpx; r=httpx.get('http://localhost:8000/api/v1/risk/current',timeout=10); print(r.json())"
```
