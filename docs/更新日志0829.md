# 更新日志 2026-08-29

## 开发者视频分析工具

- 在 AI 分析画面增加右侧悬浮开发者工具，可选择本地视频进行功能验证。
- 视频选择后先暂存，确认点击“开始分析”后再替换当前萤石或手工视频源。
- 支持 `.mp4`、`.avi`、`.mov`、`.mkv`、`.webm`，暂存文件使用不透明 ID、受控临时目录和过期清理机制。
- 监控运行中也可以选择视频；确认启动时自动停止旧监控，保留人体识别、环境识别、风险评分和 WebSocket 推送链路。
- 取消、启动失败、视频自然结束、手动停止及服务关闭时清理临时上传文件，不向前端暴露服务器绝对路径。

## 视频画面自适应

- 根据分析 WebSocket 首帧的真实像素尺寸计算显示比例。
- 将显示比例限制在 `3:4` 至 `16:9`，超窄竖屏视频在 `3:4` 画面框内缩放，超宽视频在 `16:9` 画面框内缩放。
- 分析画面新增独立比例容器，视频使用 `object-fit: contain`，完整保留画面、人体框、骨架、环境框和轨迹，空白区域使用黑色背景。
- 切换分析源时恢复默认比例，避免上一段视频的尺寸影响新视频布局。

## 环境与交互风险展示

- 右侧栏在“环境检测”标题上方独立展示“综合环境风险”和“交互风险”。
- 两项均使用统一的 `0–100` 工程风险分并保留一位小数，数据不可用时显示 `--` 并保留对应状态。
- 风险指标改为单列大字号布局，环境 provider 状态、识别目标和危险物列表继续保留。
- 开发者视频文件名移至右侧栏底部，避免遮挡分析画面。
