# 更新日志 2026-08-29

## 开发者视频分析工具

- 在 AI 分析画面增加右侧悬浮开发者工具，可选择本地视频进行功能验证。
- 视频选择后先暂存，确认点击“开始分析”后再替换当前萤石或手工视频源。
- 支持 `.mp4`、`.avi`、`.mov`、`.mkv`、`.webm`，暂存文件使用不透明 ID、受控临时目录和过期清理机制。
- 监控运行中也可以选择视频；确认启动时自动停止旧监控，保留人体识别、环境识别、风险评分和 WebSocket 推送链路。
- 取消、启动失败、视频自然结束、手动停止及服务关闭时清理临时上传文件，不向前端暴露服务器绝对路径。

## 视频画面自适应

- 根据分析 WebSocket 首帧的真实像素尺寸计算显示比例。
- 将显示比例限制在 `3:4` 至 `16:9`，超窄竖屏视频在 `3:4` 画面框内缩放，超宽视频在 `16:9` 画面框内缩放。
- 分析画面新增独立比例容器，视频使用 `object-fit: contain`，完整保留画面、人体框、骨架、环境框和轨迹，空白区域使用黑色背景。
- 切换分析源时恢复默认比例，避免上一段视频的尺寸影响新视频布局。

## 环境与交互风险展示

- 右侧栏在“环境检测”标题上方独立展示“综合环境风险”和“交互风险”。
- 两项均使用统一的 `0–100` 工程风险分并保留一位小数，数据不可用时显示 `--` 并保留对应状态。
- 风险指标改为单列大字号布局，环境 provider 状态、识别目标和危险物列表继续保留。
- 开发者视频文件名移至右侧栏底部，避免遮挡分析画面。

## v0.3.2 环境交互模型接入

- 接入 `competition_handoff_v0.3.2` 的路径交互风险算法，按预测轨迹与障碍物 corridor 的重叠比例、紧迫度和置信度计算交互工程分。
- 交互结果新增 `path_overlap_ratio` 与 `max_path_overlap_ratio` 证据字段，便于前端和后续客户端解释风险来源。
- 环境主风险分仅融合物体邻近风险与脚部通道障碍风险；Lighting 保持独立 provider，不再直接抬高环境主分。
- 实时状态标记为 `risk_extensions_v0_3_2`，同步输出人体、环境、交互三项 0–100 工程风险指数及状态。
- Wet Floor 继续明确返回 `UNKNOWN`，不伪造缺失模型结果。

## 微信云函数推送联调

- 新增微信云函数 `fallAlarmPush` HTTP 上报适配器，按交接契约发送 `elderId`、`riskLevel`、`riskScore`。
- 通过 `WECHAT_FALL_ALARM_PUSH_ENABLED=1` 启用，地址可由 `WECHAT_FALL_ALARM_PUSH_URL` 覆盖；默认不开启外部请求。
- 通知详情新增 `cloud_push` 状态，记录 `sent`、`failed` 或 `not_configured`，云函数异常不会中断本地告警和 WebSocket 链路。
