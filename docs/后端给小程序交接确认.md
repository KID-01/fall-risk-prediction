## 3. 风险等级规则

| 值 | 含义 | 小程序行为 |
| --- | --- | --- |
| `low` | 低风险 | 后端仅本地记录，不推送云函数 |
| `attention` | 关注级 | 写入云端列表，不触发微信订阅推送 |
| `critical` | 高危级 | 写入云端列表，触发高危提醒并要求确认 |

`riskScore` 为 0-100 的工程风险指数，不是医学概率。

## 4. 后端发送格式

后端生产配置使用 `hybrid` 模式，推送请求如下：

```json
{
  "action": "push",
  "elderId": "default",
  "riskLevel": "critical",
  "riskScore": 80.3,
  "data": {
    "risk_level": "critical",
    "risk_score": 80.3,
    "risk_label": "跌倒高危",
    "title": "跌倒高危告警",
    "message": "人体异常与环境风险叠加，请立即确认现场情况",
    "elderId": "default",
    "alertTime": "2026-08-30 16:30:00",
    "isRead": false
  }
}
```

云函数至少应读取并保存：`risk_level`、`message`、`elderId`、`alertTime`、`isRead`；建议同时保存 `risk_score`、`risk_label`、`title` 和 `createTime`。

## 5. 小程序调用格式

拉取列表：

```json
{"action":"pull","limit":10}
```

确认告警：

```json
{"action":"confirm","id":"云数据库记录_id"}
```

成功响应统一使用 `code: 0`。小程序应按 `_id` 去重，按 `createTime` 倒序展示；确认成功后将 `isRead` 显示为 `true`。
