## 一、环境准备

### 1.1 必备软件

| 软件 | 版本要求 | 用途 |
|------|---------|------|
| Python | ≥ 3.10 | 后端运行 |
| Node.js | ≥ 18 | 前端构建 |
| Git | 任意 | 拉取代码 |

> Docker **不需要**安装。Docker 是生产部署方案，功能测试直接本地运行即可。

### 1.2 Python 环境配置

```bash
# 1. 克隆代码
git clone <仓库地址>
cd fall-risk-prediction

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# macOS/Linux:
source venv/bin/activate

# 4. 安装项目依赖（含 fastapi/uvicorn/ultralytics/torch 等）
pip install -e ".[dev]"

# 5. 验证环境
python scripts/check_env.py
```

## 七、萤石视频流接入测试（可选）

> 仅当已有萤石摄像头设备且已激活套餐时测试。

### 7.1 激活设备

1. 登录 https://open.ys7.com（账号见 `configs/ezviz.yaml`）
2. 获取摄像头设备序列号 `deviceSerial`
3. 用激活码激活套餐（激活码已存在 `configs/ezviz.yaml`）

### 7.2 获取 RTSP 流

```bash
python -c "
import asyncio
from src.ezviz import EzvizClient
from src.utils.config import get_ezviz_config

async def main():
    cfg = get_ezviz_config()
    client = EzvizClient(cfg.ezviz.app_key, cfg.ezviz.app_secret)
    await client.ensure_token()
    devices = await client.list_devices()
    for d in devices:
        serial = d.get('deviceSerial')
        url = await client.get_rtsp_url(serial)
        print(f'设备: {d[\"deviceName\"]}  RTSP: {url}')
    await client.close()

asyncio.run(main())
"
```

### 7.3 接入系统

将获取到的 RTSP 地址作为 source 启动监控：
```bash
python scripts/demo_report.py --source "rtsp://..."
```

或在前端看板启动监控时传入 RTSP 地址（需修改 `App.jsx` 中 `startMonitor` 的 source）。

## 九、常见问题排查

### Q1: `uvicorn: 无法将"uvicorn"项识别为...`

**原因**：未激活虚拟环境。  
**解决**：
```bash
# Windows
.\venv\Scripts\Activate.ps1
# 确认命令提示符前出现 (venv)
# 重新运行 uvicorn
```

### Q2: `ModuleNotFoundError: No module named 'ultralytics'`

**原因**：依赖未装全。  
**解决**：
```bash
pip install -e ".[dev]"
```

### Q3: YOLO-Pose 模型下载失败

**原因**：网络问题，GitHub Releases 访问不畅。  
**解决**：手动下载 `yolov8n-pose.pt` 放到 `checkpoints/` 目录：
- 下载地址：https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n-pose.pt

### Q4: 前端连接状态显示"未连接"

**原因**：后端未启动，或端口被占用。  
**解决**：
```bash
# 确认后端已启动
curl http://localhost:8000/health

# 如果端口 8000 被占用，换端口启动
uvicorn src.api.main:app --host 0.0.0.0 --port 8001
# 同时修改 frontend/vite.config.js 中的代理目标端口
```

### Q5: 摄像头启动失败

**原因**：无摄像头或被其他程序占用。  
**解决**：改用视频文件测试：
```bash
python scripts/demo_report.py --source path/to/video.mp4
```

### Q6: 基线一直不就绪（samples 不增长）

**原因**：视频中没有检测到有效人体（帧质量过滤全部不通过）。  
**解决**：确保画面中有人体完整出现，下肢关键点可见。

### Q7: Docker 构建失败

**原因**：Docker Desktop 未安装或未启动。  
**解决**：安装 Docker Desktop 并启动，或跳过 Docker 测试（第八节为可选）。
