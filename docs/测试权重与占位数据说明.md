# 测试权重与占位数据

已通过 `.venv` 生成以下本地测试文件（这些文件被 `.gitignore` 忽略，不提交到仓库）：

| 文件 | 用途 | 是否是项目训练成果 |
|---|---|---|
| `checkpoints/test_best.pt` | 加载 `FallRiskPredictor`、验证前向推理和接口 | 否，随机初始化 |
| `checkpoints/yolov8n.pt` | 人体检测链路测试 | 否，Ultralytics 官方预训练模型 |
| `checkpoints/yolov8n-pose.pt` | 姿态关键点提取链路测试 | 否，Ultralytics 官方预训练模型 |
| `data/keypoints/fixture_*.npy` | Dataset/DataLoader 的合成关键点输入 | 否，测试数据 |
| `data/labels/fixture_labels.json` | 合成样本的风险等级和分数 | 否，测试标签 |

重新生成：

```powershell
.\.venv\Scripts\python.exe scripts\generate_test_fixtures.py --download-yolo
```

只生成关键点和标签、不生成项目 checkpoint：

```powershell
.\.venv\Scripts\python.exe scripts\generate_test_fixtures.py --skip-model
```

注意：`test_best.pt` 只能证明模型文件格式、参数结构和前向接口可用，不能用于准确率、误报率或跌倒识别效果。正式结果必须使用真实采集/标注数据训练后产生的 `best.pt`；YOLO 官方文件也只是通用预训练权重，不能替代项目数据上的训练与评测。
